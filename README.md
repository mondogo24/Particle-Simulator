# WHAT IT IS
Particle Simulator is a program that simulate common physical interactions. Making it a suitable program for simple studies
on multiple particles interactions or just watching a bunch of balls doing stuff.

# CAPABILITIES
There are a few features that this program is aiming to have
- Gravitational interactions (WIP)
- Collisions and interactions (Maybe, but strongly considerated)
- Quantum mechanincs (Maybe)
